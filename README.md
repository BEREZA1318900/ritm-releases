# Ритм

Нативный тренажёр слепой печати для macOS 27 и новее. Русская ЙЦУКЕН и английская QWERTY, светлое и тёмное оформление.

## Установка

1. Откройте [последнюю версию](https://github.com/BEREZA1318900/ritm-releases/releases/latest) и скачайте ZIP.
2. Распакуйте архив и перенесите «Ритм.app» в папку «Программы» перед запуском.
3. Откройте приложение.

Приложение распространяется без платного сертификата Developer ID и нотариализации Apple. При первом запуске macOS может запросить отдельное разрешение. Порядок открытия приложения из доверенного источника описан [в инструкции Apple](https://support.apple.com/ru-ru/102445).

## Обновления

После первоначальной установки выберите **Ритм → Проверить обновления…**. В **Ритм → Настройки…** можно включить автоматическую проверку новых версий. Каждый раз скачивать и переносить ZIP вручную не требуется.

Архивы обновлений и список версий подписаны ключом Ed25519; приложение проверяет подпись перед установкой. История занятий остаётся на вашем Mac и сохраняется при обновлении.

Здесь публикуются только готовые версии приложения и файлы обновлений. Исходный код и личные данные пользователей в репозиторий не загружаются.
